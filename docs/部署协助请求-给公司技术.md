# 部署协助请求（给公司技术同事）

## 一句话

帮我把一套已经开发好的“消费者运营中台”部署到公司云端，用公司子域名提供 HTTPS 访问，并配好防火墙、数据库和备份。

## 系统情况

- 技术栈：后端 Python 3.12 + FastAPI，前端 React + Vite（已构建为静态文件）。
- 数据存储：SQLite（本地开发），生产建议 PostgreSQL。
- 本地运行正常，21 项自动化测试全部通过，代码包已就绪。
- 需要部署的服务：1 个后端服务（uvicorn，端口 8000）+ 静态前端（可由后端托管或 Nginx 反代）。

## 需要你协助做的事

### 1. 申请云资源
- 云服务器 1 台：建议 4C8G，50-100GB 云盘，5Mbps 带宽（后续可扩）。
- 云数据库 PostgreSQL：小规格 2C4G 即可（或先在服务器自建）。
- Redis：小规格（可选，任务调度缓存用）。

### 2. 子域名与 HTTPS
- 分配一个子域名，例如 `pdp.company.com`。
- 配置 DNS A 记录指向服务器。
- 配置 HTTPS 证书（公司统一证书或 Let's Encrypt），强制 HTTPS。
- 告诉我最终访问地址。

### 3. 网络与防火墙
- 安全组/防火墙只开放 80/443，以及管理用的来源 IP（或走公司 VPN）。
- 数据库、Redis 只允许内网访问，不对公网开放。
- 如果有公司统一 WAF/云防火墙，帮我接入；没有就先按安全组最小权限配置。

### 4. 部署与配置
- 给我一套服务器环境：Python 3.12 可用的方式（系统 Python 或 Docker 均可）。
- 我把代码放上去后，需要配置以下环境变量（值由我提供或你来开）：
  - 数据库连接地址
  - 管理员初始账号密码（我会改）
  - 大模型 API Key（DeepSeek / 混元，可选）
  - 短信 / 企微 / 飞书凭证（后续接入时再填）
- 启动后端服务，并把子域名 443 转发到后端（Nginx 反代或云负载均衡）。

### 5. 备份与监控
- 数据库自动备份（每日快照即可），告诉我备份位置。
- 如果公司有统一监控/日志平台，帮我接入；没有就先给服务器基础告警（CPU、内存、磁盘）。

### 6. 需要你提供给我的信息
- 服务器 IP、SSH 登录方式
- 子域名正式地址
- 数据库连接信息（或已配好的环境变量模板）
- 备份位置和策略

## 你可以不用管的部分

- 业务逻辑、运营页面、指令/策略/执行流程：已开发完成，不需要你参与。
- 短信、企微、飞书等第三方账号：我会对接，你只负责服务器环境和网络。

## 我这边会同步准备

- 完整代码包和启动脚本
- 环境变量配置模板
- 部署后联调（登录、页面访问、接口正常）

## 期望

- 希望先给到：服务器资源 + 子域名 + HTTPS + 防火墙放行，我就能开始部署联调。
