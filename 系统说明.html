核心模块

模块作用
指令中心12 维结构化指令输入，调用 LLM 生成 7 板块策略资产包
执行中心按活动 / 货盘 / 1v1 / 朋友圈 / 社群 / 短信 / 跟进分类展示，整月排期自动调度
需求飞轮热点信号采集 + 行业洞察，为人工下达指令提供参考依据
策略沉淀中心可复用策略库，支持策略自生长与跨行业复用
知识库多行业知识 + 品牌资料，资产包生成时自动检索真实素材
护栏品牌违禁词 + 语境放行，命中自动拦截告警
客户画像客户身份 / 需求 / 消费标签结构化沉淀
行业配置美业 / 餐饮 / 零售 / 教育 / 宠物 / 大健康模板，切换即全系统适配
开发者后台神经元中枢：平台共享策略管理、多租户隔离、模型配置
LLM 网关多模型路由配置，按成本与质量灵活切换

运行流程

  1. 需求飞轮采集市场信号，产出洞察建议
  2. 运营人员参考洞察，在指令中心下达指令（可上传品牌素材）
  3. 系统检索知识库 + 调用 LLM，生成 7 板块策略资产包
  4. 运营审阅资产包，批准后进入执行中心
  5. 执行中心生成整月排期待办，后台到点自动下发
  6. 内容经护栏校验，下发至飞书 / 企微等渠道
  7. 验收阶段回填 KPI 实际值，生成达成率报告，回传策略引擎自迭代

技术栈

后端Python 3.12 · FastAPI · SQLAlchemy 2 · Alembic · SQLite / PostgreSQL

前端React · Vite · TypeScript

模型OpenAI 兼容协议 · Ollama / DeepSeek / 混元 / GPT

部署Docker · macOS LaunchAgent · 云端可迁移

多租户架构

采用「神经元中枢 + 品牌分支」模型：开发者后台为神经元本体，平台级策略 / 模板默认共享；品牌为分支，业务数据完全隔离，可覆盖私有内容。支持 AI 变异生成新策略，人工审核后入库自生长。

完整开发方案见 docs/开发方案.md，迭代规划见 中台迭代2.0方案.html。
